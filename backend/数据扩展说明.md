# 数据扩展说明

## 1. 目标

这个项目现在保留的是“登录服务器 + 数据库 + 基础农场 + 简化背包数据”的最小可用结构。

后续如果要继续扩展数据，只需要沿用当前思路：

- `users` 表保存账号和基础资源
- `farm_plots` 表保存农场地块状态
- `player_inventory` 表保存玩家背包物品

---

## 2. 当前保留的数据模型

### 2.1 `users` 表

字段：
- `id`
- `username`
- `password_hash`
- `salt`
- `region`
- `coins`
- `level`
- `exp`
- `diamonds`
- `created_at`

当前默认规则：
- 新用户注册后，默认只有 `coins = 100`
- `level = 0`
- `exp = 0`
- `diamonds = 0`

测试账号保留：
- `admin / admin123`
- `player001 / 123456`
- `player002 / 123456`
- `player003 / 123456`
- `test / test123`

### 2.2 `farm_plots` 表

字段：
- `id`
- `user_id`
- `plot_index`
- `state`
- `crop_type`
- `planted_at`
- `grow_stage`

用途：
- 为每个用户生成 24 块农场地块
- 供登录服务器和农场界面读取

### 2.3 `player_inventory` 表

字段：
- `id`
- `user_id`
- `item_id`
- `item_name`
- `icon`
- `category`
- `count`
- `value`
- `acquired_at`

用途：
- 保存玩家背包物品
- 供 GameRoot / 背包系统读取与持久化

---

## 3. 当前后端接口

### 3.1 登录与注册

- `POST /api/login`
- `POST /api/register`

作用：
- 登录校验
- 注册新用户
- 返回用户基础信息

### 3.2 GameRoot 兼容接口

- `GET /api/game/state`
- `POST /api/game/inventory`

作用：
- 返回用户基础资源和背包数据
- 接收背包数据并写入数据库

### 3.3 农场接口

- `GET /api/farm`
- `POST /api/farm/action`

作用：
- 获取农场地块状态
- 处理地块操作（开发 / 浇水 / 施肥）

---

## 4. 以后新增数据时的建议

### 4.1 新增用户字段

如果想加新的玩家属性，优先考虑：
- 继续放在 `users` 表中
- 但只放“基础属性”，不要把所有业务内容都塞进去

### 4.2 新增物品/背包数据

如果要新增“物品、背包、商店、任务”等内容，建议：
- 物品定义用 `player_inventory` 这类数据表存储玩家持有情况
- 如果以后要扩展为正式物品系统，再增加 `items` 模板表

### 4.3 新增农场字段

如果要扩展农场内容，可以继续在 `farm_plots` 中增加字段，例如：
- `water_level`
- `fertility`
- `harvest_time`

## 5. 当前数据库的详细情况

### 用户基础表

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INT | 主键，自增 |
| `username` | VARCHAR(32) | 登录账号，唯一 |
| `password_hash` | VARCHAR(128) | 密码哈希 |
| `salt` | VARCHAR(64) | 密码盐 |
| `region` | VARCHAR(64) | 所属大区 |
| `coins` | INT | 金币，默认 100 |
| `level` | INT | 等级，默认 0 |
| `exp` | INT | 经验，默认 0 |
| `diamonds` | INT | 钻石，默认 0 |
| `created_at` | DATETIME | 注册时间 |

### 农场地块表

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INT | 主键 |
| `user_id` | INT | 所属用户 |
| `plot_index` | INT | 地块编号 0-23 |
| `state` | VARCHAR(4) | 地块状态 |
| `crop_type` | VARCHAR(32) | 作物类型 |
| `planted_at` | DATETIME | 种植时间 |
| `grow_stage` | INT | 生长阶段 |

### 背包物品表

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INT | 主键 |
| `user_id` | INT | 所属用户 |
| `item_id` | VARCHAR(64) | 物品ID |
| `item_name` | VARCHAR(128) | 物品名称 |
| `icon` | VARCHAR(128) | 图标名 |
| `category` | VARCHAR(32) | 分类 |
| `count` | INT | 数量 |
| `value` | INT | 回收价 |
| `acquired_at` | DATETIME | 获得时间 |

---

## 6. 说明文件与脚本

当前保留的核心文件：

- `database.py`：数据库建表、初始化、查询、保存背包数据
- `server.py`：启动 Flask 服务，提供登录/注册/游戏接口
- `export_db_to_csv.py`：导出数据库为 CSV
- `docs/database_guide.md`：数据库说明

其余不必要的内容已尽量精简。
