1. 技术栈与目录结构
引擎：Cocos Creator 3.8.x，语言 TypeScript
场景：scenes/farm.scene（农场主场景）、登录场景在 scenes/ 下
资源：resources/（全部由 Cocos 按目录加载，代码用路径字符串引用）
纯逻辑层不依赖引擎（可单独单元测试），UI 层才引入 cc 模块。

2. 分层架构总览
整个项目遵循 「配置 → 数据模型 → UI → 顶层装配」 单向依赖，避免循环：

text

  config/（纯数据常量）
     ↓ 被读取
  data/（纯逻辑模型：计算、状态、存档）
     ↓ 被驱动
  ui/（视图组件：渲染 + 交互 + 动画）
     ↓ 被装配
  GameRoot（挂在 Canvas，负责一切初始化与回调接线）
     ↓ 依赖
  login/Net + data/FarmApi（网络层）
层	职责	典型文件	是否依赖引擎
配置层	集中所有可调数值，只导出常量/纯函数	config/*	否
数据层	保存运行态、做模拟计算、序列化存档	data/FarmModel.ts 等	否
UI 层	读模型 → 渲染到节点；接收点击 → 调用模型；播放动画	ui/LandView.ts 等	是
装配层	绑定场景节点、初始化、接线回调、持久化	GameRoot.ts	是
网络层	HTTP 请求封装与 API	Net.ts、FarmApi.ts	否（fetch）
为什么这样分？

纯逻辑层不依赖引擎 → 可以脱离 Cocos 用 Node.js 单独跑测试（正是这样验证的）。
配置集中 → 改数值不动逻辑，方便策划/你自己调平衡。
UI 与模型解耦 → 同一套逻辑可复用到网页版 Demo（farm_demo.html）。

5.11 scripts/farm/data/FarmModel.ts —— ★ 农场核心逻辑
函数	作用
constructor()	调用 reset() 建 24 块地
reset()	重建 24 块未开发地
newPlot(id)	私有：构造一块地的初始数据
getPlot(id)	按 id 查地块
isUnlocked(id, level)	该地块在当前等级是否解锁
landState(p)	显示态计算：未开发→b；水<30→d；肥≥50→c；否则 a（优先级 b>d>c>a）
growthStage(p, stages)	按进度算当前生长阶段下标（用于选贴图）
develop(id)	开发一块地；新地初始水分设到 30（显示普通态）
plant(id, cropId, level)	种植：必须已开发、空着、已解锁
water(id, amount)	浇水：水分 +amount（默认 +20，封顶 100）
fertilize(id, amount)	施肥：肥料 +amount（封顶 100）
harvest(id)	收获：必须成熟，返回作物价值，清空该地作物（保留水肥）
updateModel(nowMs)	时间推进主入口：按真实时间逐小时结算
tickHour(stepEnd, frac)	私有：结算一小时内的耗水/耗肥/生长/奖励
hourKey(ms)	私有：生成 YYYYMMDDHH 用于 0/12 点奖励去重
envMultiplier(p, def)	计算生长环境系数：在最佳区间≈1，偏离越多越小（最低 0.04）
toJSON() / loadJSON()	存档 / 读档（含离线补算）
核心循环（updateModel → tickHour）：

计算从 lastTick 到现在经过了几个小时。
逐小时推进（保证 0/12 点边界准确）。
每小时：按天气扣水 → 有作物则扣肥 → 按 envMultiplier 推进生长 → 跨 0/12 点且水肥达标则 +2h 奖励。

8. 关键机制深挖
8.1 土地显示态优先级
landState(p)：未开发 b > 缺水 d > 施肥 c > 普通 a。

例：水20（<30）肥50 → d（缺水优先）。
浇水后水40（≥30）肥50（≥50）→ c。
8.2 生长速度（envMultiplier）
良好生长 = envMultiplier≈1 → 12 小时成熟（duration=12）。
最佳区间外：按 penalty* 逐点扣减速；水分<20 额外惩罚；最低 0.04（几乎不长）。

8.3 0/12 点奖励
tickHour 里当 hour===0 || hour===12 且 water≥boostWater && fert≥boostFert → progress += boostHours/duration（+2h），用 lastBoostKey=YYYYMMDDHH 去重，避免同小时重复触发。

8.4 离线补算
lastTick 记录上次结算时间；updateModel(now) 把间隔按小时切成片段逐段结算，所以离线时长也会正确反映到水/肥/生长上。

8.5 等级 → 解锁 → 难度
解锁：plotsUnlockedAtLevel(level)，1 级 1 块，逐级变多。
升级难度：expForNextLevel = ceil(100 × 1.5^(level-1))，指数增长 → 越来越难。

# 农场·土地种植系统设计说明

本文档说明整套「土地显示 + 种植模拟 + 浇水施肥」是如何工作的，以及**所有可调参数放在哪**。
想调数值，只改对应配置文件即可，无需动其它逻辑。

## 一、整体架构（文件 → 职责）

| 文件 | 作用 |
|------|------|
| `scripts/farm/config/LandConfig.ts` | **土地/升级配置**（总量、阈值、浇水值、等级解锁、升级经验曲线） |
| `scripts/farm/config/WeatherConfig.ts` | **天气配置**（每小时水分消耗） |
| `scripts/farm/config/CropConfig.ts` | **作物配置**（每种作物的生长时长/阶段/最佳水肥/价值） |
| `scripts/farm/data/PlotData.ts` | 地块/作物类型定义 |
| `scripts/farm/data/FarmModel.ts` | **核心逻辑**：水分/肥料消耗、生长模拟、0/12点奖励、显示态(a/b/c/d)、存档 |
| `scripts/farm/data/PlayerModel.ts` | 玩家金币 / 等级 / 经验 |

## 二、土地显示规则（a/b/c/d）

每块地的土地贴图路径为 `resources/farm/lands_{状态}1/locked_{行}{状态}`（正好复用你现成的 24×4 张图）。

显示优先级（`FarmModel.landState()`）：

1. 未开发 → **b**（草地/未开发样式）
2. 水分 < 阈值 → **d**（缺水，优先显示，如你举的例：水20/肥50 显示 d）
3. 肥料 >= 阈值 → **c**（施肥后）
4. 否则 → **a**（普通）

> 你举的例：水=20（<30 → d）、肥=50；浇水后水=40（≥30）、肥=50（≥50）→ 显示 **c**。✓

### 等级解锁
- 1 级只显示 `lands_1` 的第 1 块地；等级越高解锁越多（见 `LEVEL_PLOTS`，约 10 级解锁满 24 块）。
- 未解锁的地块隐藏；已解锁但没开发的地块显示 **b**，点击花金币开发后显示 a/c/d 并可变现可种植。

### 主要数值（`LandConfig.ts`）
```
TOTAL_PLOTS=24  PLOTS_PER_ROW=6  ROWS=4
WATER_MAX=100   FERT_MAX=100
DRY_THRESHOLD=30        // 缺水显示 d
FERT_FERTILIZED=50      // 施肥显示 c
WATER_PER_USE=20        // 一次浇水 +20
DEVELOP_COST=50         // 开发一块地
LEVEL_PLOTS=[1,2,4,6,9,12,15,18,21,24]   // 每级解锁数
LEVEL.BASE_EXP=100  LEVEL.EXP_GROWTH=1.5 // 升级越来越难
```

## 三、水分与肥料

- 水分/肥料总量上限各 100。
- **水分每小时消耗**由 `WeatherConfig.ts` 决定：
  - 晴 38° ≈ 8.3/小时（≈ 6 小时减 50，贴合你的设定）
  - 多云 5.5/h、雨 1.5/h、夜 2.5/h（每天 24 小时的排表在 `DAY_SCHEDULE`）
- **肥料每小时消耗**按作物配置里的 `fertConsume`（约 0.7/h）。
- **一次浇水 +20**（`WATER_PER_USE`）。
- **不同化肥养分不同**：在 `LandConfig.ts` 的 `FERT_AMOUNTS` 里按化肥贴图名配置（如 `fert_compound:30`、`fert_organic:18`、`fert_slow:35`）。

---

## 四、作物生长

### 关键机制
1. **良好生长 = 12 小时可收获**：每种作物 `duration=12`，当水/肥都在最佳区间时，生长系数 ≈1 → 12 小时成熟。
2. **最佳水/肥区间**（`optWater` / `optFert`）：**超出或不足都会降速**（`FarmModel.envMultiplier()`）。水分低于 20 还有额外惩罚。
3. **生长阶段**：每作物的 `stageIcons` 决定阶段贴图（种子 → plant_1 → plant_2 → plant_3 → 成熟用 `fruit_*`）。阶段随进度切换。
4. **0 点 / 12 点奖励**：跨过 0 点或 12 点时，若水≥`boostWater`(40) 且肥≥`boostFert`(30)，一次性 `+boostHours`(2 小时) 生长（去重，不重复叠加）。
5. **离线补算**：`FarmModel` 存 `lastTick`，重开时按真实时间逐小时回算，不会因为没在线而卡进度。

### 数值在哪改（`CropConfig.ts`）
```
duration: 12                     // 良好生长小时数
stageIcons: [seedIcon, plant_1, plant_2, plant_3]   // 阶段贴图
optWater:[55,75]  optFert:[40,60]  // 最佳区间（超出/不足降速）
boostWater:40  boostFert:30  boostHours:2            // 0/12点奖励
fertConsume:0.7                 // 每小时肥料消耗
value:20                        // 收获金币
```
想加新作物：在 `CROPS` 数组里加一行 `build(...)` 即可。

### 收获 & 升级
- 成熟后点击收获，获得金币 + 经验（经验 = 价值/2）。
- 经验够了自动升级，升级经验按 `EXP_GROWTH` 指数增长（越来越难），升到更高等级解锁更多地块。
- 收获获得的金币会进背包/顶栏金币。

## 五、交互与动画

左侧工具栏 `LefttBar` 里有两个节点：**Water（浇水）** 和 **Fertilizer（施肥）**，`GameRoot` 按节点名自动绑定：

- 点 **Water** 进入浇水模式 → 点一块已开发的地 → 浇水动画（土块弹跳 + `+20 💧` 飘字 + 水珠上飘）。
- 点 **Fertilizer** 进入施肥模式 → 点一块地 → 弹出**化肥选择框**（列出背包里的化肥 + 各自养分）→ 选择后播放施肥动画（土块弹跳 + `+N 🧪` + 肥雾扩散）。
- 未选工具时点地：**未开发**→开发；**空**→选种子种植；**可收获**→收获；**生长中**→查看状态（水/肥/剩余时间）。

动画用 tween 实现（弹跳 + 飘字 + 水珠/肥雾贴图），贴图在 `resources/farm/effect/`。
