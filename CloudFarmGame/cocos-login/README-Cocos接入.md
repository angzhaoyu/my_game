# 把登录系统接到 Cocos Creator（微信小游戏）上

> 前端：Cocos Creator 3.8.x + TypeScript（UI 全代码构建，不用手动画界面）
> 后端：Flask + MySQL（上一教程跑起来的那个，接口完全复用，不用改后端逻辑）
> 本文件夹 `cocos-login/` 就是你要拷进 Cocos 工程的东西。

---

## 一、需要准备的东西

| 软件 | 用途 | 已装？ |
|------|------|--------|
| Cocos Creator 3.8.x | 游戏引擎（含浏览器预览） | 需安装 |
| 后端（game-login-mysql） | 登录接口，**要在电脑上跑着** | 上一步已配好 |
| 微信开发者工具 | 打包/预览微信小游戏（浏览器预览不需要它） | 可选 |

**安装 Cocos Creator**：https://www.cocos.com/creator-download → 下载「Cocos Dashboard」→ 安装后在 Dashboard 里装 **3.8.x 版本**（本教程按 3.8 写）。

---

## 二、三步搞定对接

### 第 1 步：确认后端在跑（并已支持跨域）

浏览器打开 **http://127.0.0.1:8000/api/regions**，能返回 JSON（大区列表）就 OK。
> 本教程配套的后端 server.py 已加上 CORS 跨域支持，Cocos 预览页面（端口 7456）才能请求到你的后端（端口 8000）。

### 第 2 步：新建 Cocos 工程 + 拷贝脚本

1. Cocos Dashboard → 新建项目 → 选 **Empty(2D)** → 起名 `LoginDemo` → 创建
2. 用文件管理器打开工程目录，把本文件夹的 `assets/scripts/` 整个拷进工程的 `assets/` 下
   （最终应该是 `assets/scripts/LoginMain.ts`、`Net.ts`、`ServerConfig.ts`）
3. 回到 Cocos 编辑器，等待右下角编译完成、**没有任何报错**

### 第 3 步：建场景、挂组件、预览

1. 在 `assets` 里右键 → 创建 → **场景** → 命名为 `login`，双击打开
2. 层级管理器右键 → 创建 → UI 组件 → **Canvas**（会自动带上 Camera）
3. 选中 **Canvas** 节点 → 右侧「属性检查器」→ 底部「**添加组件**」→ 搜索 `LoginMain` → 点击添加
4. **Ctrl+S 保存**
5. 点顶部工具栏的**浏览器预览**按钮（▶）
6. 预览窗口右上角选 **1280 × 720**（横屏）→ 就能看到游戏登录界面了！

**测试**：账号 `admin` 密码 `admin123`，大区选「大区一 · 电信」→ 登录成功进入游戏主页，看到金币 99999 / 等级 60 / 钻石 8888 和经验条。
故意输错密码、选错大区，都能看到失败提示（这就是与后端数据库比对的效果）。

## 三、真机（手机）横屏测试

1. cmd 里输入 `ipconfig` 找 **IPv4 地址**（如 192.168.1.5）
2. 打开 `assets/scripts/ServerConfig.ts`，把 `baseUrl` 改成 `http://192.168.1.5:8000`
3. 手机连**同一个 Wi-Fi**，在 Cocos 预览窗口点**二维码图标**，手机扫码打开，横过来
4. Windows 弹出防火墙提示 → 点「允许访问」

> 记得测试完把 `baseUrl` 改回 `http://127.0.0.1:8000`（浏览器预览用）。

---

## 四、打包成微信小游戏（横屏）

1. 菜单 **项目 → 构建发布** → 平台选 **微信小游戏**
2. 游戏名称随便填；**AppID** 填测试号 `touristappid`（没有正式 AppID 也能预览）
3. 「方向」选 **横屏 landscape**（或拷贝本文件夹里 `微信小游戏配置/game.json` 到生成目录根目录）
4. 点「构建」，完成后点「打开」用**微信开发者工具**导入生成目录（build/wechatgame）
5. 微信开发者工具 → 右上「详情」→「本地设置」→ **勾选「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」**（开发阶段必须，否则连不上 http）
6. 点「编译」→ 左边模拟器里横屏显示登录界面 → 登录测试

> 真机预览：微信开发者工具 → 点「预览」→ 手机微信扫码。手机和电脑要在同一 Wi-Fi。

## 五、代码结构说明

```
cocos-login/assets/scripts/
├── LoginMain.ts      # 主组件：UI 全代码构建 + 登录/注册/大区/主页逻辑（挂到 Canvas 即可）
├── Net.ts            # 网络封装：自动识别微信小游戏(wx.request) / 浏览器预览(XMLHttpRequest)
└── ServerConfig.ts   # 服务器地址配置（改这里切换 本机/局域网/线上）
```

- **为什么要全代码构建 UI**：省去手动画界面的步骤，挂一个组件就能跑，也方便以后直接改布局。
- **Net.ts 的适配逻辑**：在微信里走 `wx.request`，在浏览器预览里走 `XMLHttpRequest`，同一个接口、同一份返回 JSON，两边代码共用。

## 六、正式上线前要做的（了解即可）

1. **微信登录**：现在用的是「账号+密码」模拟登录。正式小游戏通常先 `wx.login()` 拿 code → 后端 `code2Session` 换 openid → 用 openid 关联你的 `users` 表（比对逻辑一模一样，只是把账号换成 openid）
2. **HTTPS + 域名**：微信要求 request 域名必须 HTTPS 且在公众平台配置「request 合法域名」；后端要部署到云服务器（数据库可换云 MySQL）
3. **数据库**：本地 MySQL → 腾讯云/阿里云 MySQL，`config.py` 改一下连接地址即可

## 七、常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 预览时「无法连接服务器」 | 后端没启动 / 地址不对 | 确认 python server.py 在跑；ServerConfig.ts 的 baseUrl 对不对 |
| 提示「Failed to fetch」或跨域报错 | 后端没加 CORS | 用本教程配套的最新 server.py（已加 CORS）重启后端 |
| 登录成功但主页没数据 | 大区选错了 | 后端会返回该账号所属大区提示，切换大区再试 |
| 场景里一片黑 | LoginMain 挂错节点 | 必须挂在 **Canvas** 节点上（不是普通空节点） |
| 编译报错 | Cocos 版本太旧 | 用 3.8.x（3.6+ 大部分能兼容，报错就按提示改） |
| 微信模拟器里白屏 | 没勾「不校验合法域名」 | 开发者工具 → 详情 → 本地设置 → 勾上 |
